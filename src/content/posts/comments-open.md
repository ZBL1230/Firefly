## 终于，可以评论了

就在今天，我的个人网站「ZBL神奇宝库」（zblweb.top）正式开放了评论系统。

从今天起，你在每篇博文、留言板、友链页的底部，都能看到一个评论框——不用注册、不用登录，填个昵称就能说话。你可以夸我、骂我、提问、唠嗑，每一条评论我都会认真看、认真回。

对一个博客来说，评论区看似只是页面底部的一小块，但对我而言，它是这个网站从「一个人的独白」变成「一群人的交流」的标志。

## 回头看：这个站是怎么来的

「ZBL神奇宝库」从立项到上线，再到今天，每一步都不是一键完成的。

**选框架就纠结了很久。** 最后选了 Astro + Firefly 主题（基于 Fuwari 二次开发的国产开源模板）——理由很简单：构建快、纯静态、对中文排版友好，而且主题源码写得干净，想改哪里都能下手。

**上线只是开始。** 模板自带的示例内容，我一条条清理：13 篇示例文章全部转入草稿、示例动态删掉重写、示例友链换成真实的朋友、关于页逐字重写成自己的话。主题色调了又调，最后定下「翡翠碧」；横幅的打字机文案，从英文占位换成一句句写给访客的中文；桌面端和移动端的背景图，各挑了十张风景图随机轮换，命名规范都统一起来，免得日后被模板更新覆盖。

**细节控的胜利。** 为了中文正文用上真正的中文字体（而不是静默回退到系统字体），研究了分片 webfont 自托管方案，把几 MB 的字体子集化到首页只加载几百 KB；为了站内搜索能搜到中文，重新跑了搜索索引；为了移动端的加载速度，图片全部转成渐进式格式并生成占位。

这些事说起来一行字，做起来都是一晚上的调试和一次次的重新构建。

## 评论系统：最后的硬骨头

静态博客没有后端，评论是出了名的「最后一公里」。我对比了主流方案：

- **Giscus**：数据存 GitHub Discussions，零成本，但访客得有 GitHub 账号——对不折腾的读者太不友好；
- **Waline / Artalk**：功能全，但部署链路长；
- **Disqus**：国内访问体验堪忧。

最终选了 **Twikoo**：全中文界面、访客填昵称邮箱即可发言、有完善的管理后台和邮件通知。

选好了才是折腾的开始。为了给它找个既免费又稳定的家，我注册了 MongoDB Atlas 建数据库、在 Netlify 上部署了云函数。中间踩了个隐蔽的坑：Netlify 新建的站点默认是「私密」的，自己登录着测一切正常，访客却全被登录墙拦住，评论一律失败——排查了好一会儿才发现这个「贴心」的新默认值。关掉访问控制的那一刻，测试评论「唰」地出现在列表里，成就感拉满。

前端的评论脚本也做了针对性优化：JS 从国内 CDN 加载，版本与后端严格对齐，确保加载快、兼容稳。

## 写在最后

建站这件事，最大的乐趣从来不是「上线」那一瞬间，而是把一个个「暂时不行」变成「搞定了」的过程。今天又搞定了一个。

所以——这个评论区，就是为你准备的。

不管你是偶然路过的陌生人，还是一直关注我的朋友，都欢迎来[留言板](/guestbook/)说句话。你的每一条评论，都会成为这个宝库里新的收藏。
